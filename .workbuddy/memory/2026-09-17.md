### 踩坑（已写入 README「常见问题」与技能 springboot-vue-win-sandbox）
1. Git Bash 下 `mvnw`/`mvn` 因 MSYS 改写 `-classpath` 报 `ClassNotFoundException: Launcher` → 用 java 直接拉 plexus-classworlds
2. IDE 自动构建往 `target/classes` 写脏 class，Maven 增量编译跳过 → 必须 `clean compile`
3. Sa-Token 注解鉴权需手动注册 `SaInterceptor`，且必须实现 `StpInterface` 才有角色
4. jsoup 清洗时 baseUri 为空会把 `/upload/...` 相对地址当非法协议删掉
5. 沙箱 safe-delete 会拦截 Node `rmSync` 批量删除（>50 文件）→ 脚本改覆盖式拷贝
6. 同一文件不要并行发两个 Edit（后写覆盖前写，丢改动）
