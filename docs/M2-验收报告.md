## 2. 本次修复的关键缺陷

| # | 问题 | 影响 | 处理 |
|---|---|---|---|
| 1 | `ArticleServiceImpl` 重复定义 `toPageItem()` | **项目无法编译**，M2 完全起不来 | 重写服务层 |
| 2 | `ArticleMapper.xml` 放在 `src/main/java/**`，而 `mapper-locations=classpath*:mapper/*.xml` | 手写 SQL 未加载，列表接口必报 Invalid bound statement | 移至 `resources/mapper/` |
| 3 | 未注册 `SaInterceptor` | `@SaCheckLogin` / `@SaCheckRole` 全部失效（后台可被游客调用） | 新增 `SaTokenConfig` |
| 4 | 未实现 `StpInterface` | 角色恒为空，管理员也被判 403 | 新增 `StpInterfaceImpl`（读 `user.role`） |
| 5 | `content_html` 从未生成 | 前台详情页正文空白 | 发布/编辑已发布文章时渲染并清洗 |
| 6 | 详情 VO 缺 author/category/tags | 列表与详情缺作者、分类、标签 | 批量回填（避免 N+1） |
| 7 | 上传目录用相对路径 `./upload` | `MultipartFile#transferTo` 解析到 Tomcat 临时目录，上传必失败 | 启动时转绝对路径 + `Files.copy` |
| 8 | Spring multipart 默认上限 1MB | 超过 1MB 的图片直接 500“系统繁忙” | 配置 5MB/10MB + 友好提示 |
| 9 | 编辑时前端把 `contentHtml` 回填进编辑器 | 二次保存会把 HTML 当 Markdown 存库 | 新增 `GET /api/article/{id}/edit` 返回原文 |
| 10 | 驳回后无法重新提交、下架后管理员无法再发布 | 状态机断链 | 提交允许 0/3 → 1；管理员可直接发布非发布态文章 |
| 11 | 后台管理列表调用的是**前台**接口 | 草稿/待审核/已驳回在管理页不可见 | 改用 `/api/admin/article/page` |
| 12 | `NotLoginException` 落入兜底异常 | 未登录返回 500“系统繁忙”，前端无法识别 | 统一映射 401/403/400/404 |

## 3. 接口清单（M2）

```
# 公开
GET    /api/article/page            已发布文章分页（categoryId / tagId / keyword / page / size）
GET    /api/article/{id}            详情（仅已发布，阅读量 +1）
GET    /api/category/list           分类列表（sort 升序）
GET    /api/tag/list                标签列表
GET    /upload/**                   上传图片访问（虚拟路径映射）

# 登录用户
GET    /api/article/mine            我的文章（status 可选）
GET    /api/article/{id}/edit       编辑回显（Markdown 原文 + tagIds）
POST   /api/article                 新建（action 0=草稿 1=提交审核 2=管理员直接发布）
PUT    /api/article/{id}            编辑
POST   /api/article/{id}/submit     提交审核
DELETE /api/article/{id}            删除（逻辑删除）
POST   /api/upload/image            上传图片

# 仅 ADMIN
GET    /api/admin/article/page      全量文章分页
POST   /api/admin/article/{id}/publish   审核通过并发布
POST   /api/admin/article/{id}/reject    驳回（body: {reason}）
POST   /api/admin/article/{id}/offline   下架
POST   /api/category  PUT /api/category/{id}  DELETE /api/category/{id}
POST   /api/tag       PUT /api/tag/{id}       DELETE /api/tag/{id}
```

统一返回体 `{ code, message, data }`；`code` 约定：0 成功 / 400 参数 / 401 未登录 / 403 无权限 / 404 不存在 / 500 业务或系统错误。

## 4. 验收覆盖（摘要）

- **权限隔离**：游客 401、普通用户 403、管理员放行；越权建分类/审核/直发均被拒
- **写作**：草稿保存、空标题/无效分类校验、自动摘要（已清理表格语法）、标签回填
- **状态机**：0→1 提交、重复提交拦截、1→2 发布、1→3 驳回（空原因拦截）、3→1 改后重提、2→0 下架、0→2 重新发布
- **前台可见性**：待审核/草稿不出现在前台，下架后立即消失；详情阅读量自增
- **渲染**：`contentHtml` 含 `<h2>`、`<strong>`、`<pre><code class="language-java">`、`<table>`，相对图片路径 `/upload/...` 未被清洗，无 `<script>` 注入
- **上传**：PNG 成功且 `/upload/...` 可访问（200 image/png），2MB 可上传，>5MB 与 `.exe` 被拒，游客 401
- **逻辑删除**：删除后不再出现在我的文章与前台

## 5. 本地启动备忘

```bash
# 后端（8081）
mvn clean compile && mvn spring-boot:run     # 或 IDE 直接运行 MyblogApplication

# 前端（5173，proxy /api、/upload → 8081）
cd blog-frontend && npm install && npm run dev
```

- 首次需执行 `src/main/resources/db/schema.sql`，并把某个账号 `role` 改为 `ADMIN` 以使用后台
- Git Bash 里 `./mvnw` 会因 MSYS 改写 `-classpath` 而报 `ClassNotFoundException: Launcher`，改用 IDE 或直接 `java -classpath <m2>/wrapper/dists/.../boot/plexus-classworlds-*.jar ... Launcher` 启动 Maven
- 遇到 `Unresolved compilation problem`：IDE 自动构建写脏了 `target/classes`，执行 `clean compile`
- Vditor 资源由 `npm run sync:vditor` 生成到 `public/vditor/`（已 gitignore）
